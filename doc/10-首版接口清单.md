# 首版接口清单

## 认证与用户
- POST /api/v1/auth/register：注册。
- POST /api/v1/auth/login：登录。
- POST /api/v1/auth/logout：退出。
- GET /api/v1/auth/me：当前用户。
- PATCH /api/v1/users/me：编辑资料。
- GET /api/v1/users/:id：查看公开主页。

## 首页与公共数据
- GET /api/v1/home：首页聚合数据。
- GET /api/v1/categories：分类列表。
- GET /api/v1/tags：标签列表。

## 博客
- GET /api/v1/blogs：博客列表。
- POST /api/v1/blogs：创建博客草稿。
- GET /api/v1/blogs/:id：博客详情。
- PATCH /api/v1/blogs/:id：编辑博客。
- DELETE /api/v1/blogs/:id：删除博客。
- POST /api/v1/blogs/:id/publish：发布博客。

## 工具箱
- GET /api/v1/tools：工具列表。
- POST /api/v1/tools：提交工具。
- GET /api/v1/tools/:id：工具详情。
- PATCH /api/v1/tools/:id：编辑工具。
- DELETE /api/v1/tools/:id：删除工具。
- POST /api/v1/tools/:id/visit：记录访问。

## 需求
- GET /api/v1/requirements：需求列表。
- POST /api/v1/requirements：发布需求。
- GET /api/v1/requirements/:id：需求详情。
- PATCH /api/v1/requirements/:id：编辑需求。
- POST /api/v1/requirements/:id/responses：提交响应。
- GET /api/v1/requirements/:id/responses：查看响应。
- POST /api/v1/requirements/:id/close：关闭需求。

## 互动
- POST /api/v1/interactions/likes：点赞或取消点赞。
- POST /api/v1/interactions/favorites：收藏或取消收藏。
- POST /api/v1/interactions/follows：关注或取消关注。
- GET /api/v1/comments：评论列表。
- POST /api/v1/comments：发表评论。
- DELETE /api/v1/comments/:id：删除评论。
- GET /api/v1/notifications：通知列表。
- POST /api/v1/notifications/:id/read：标记已读。

## 搜索与审核
- GET /api/v1/search：全局搜索。
- POST /api/v1/reports：提交举报。
- GET /api/v1/admin/reports：管理员查看举报。
- POST /api/v1/admin/moderation/:id/approve：审核通过。
- POST /api/v1/admin/moderation/:id/hide：下架内容。
- POST /api/v1/admin/moderation/:id/restore：恢复内容。
