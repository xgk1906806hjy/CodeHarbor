# CodeHarbor 开发文档

本目录存放面向产品开发、联调、部署和维护的总体文档。具体功能细节放在 ../docs/ 对应目录。

## 文档索引
- 01-系统架构.md：系统边界、模块分层和请求链路。
- 02-数据模型.md：核心实体、字段和关系设计。
- 03-接口规范.md：接口命名、分页、错误码和权限约定。
- 04-前端开发规范.md：页面、组件、状态和交互规范。
- 05-后端开发规范.md：领域服务、校验、事务和安全规范。
- 06-本地开发与环境.md：环境变量、启动和联调要求。
- 07-测试与验收.md：测试策略和发布前检查。
- 08-部署与运维.md：构建、部署、日志和备份建议。

## 建议开发顺序
1. 认证和用户模型。
2. 内容公共模型和首页读取链路。
3. 博客、工具箱和需求模块。
4. 互动、搜索和通知。
5. 审核后台、测试和部署。
