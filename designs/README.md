# CodeHarbor 视觉方案选版

打开 `http://localhost:4173/designs/` 查看四个首页方向。

大厂组件库方向请打开 `http://localhost:4173/designs/enterprise.html`。

## 方案

- `A / Harbor Forge`：DaisyUI 设计语言，深色工程控制台，信息密度最高。
- `B / Atlas Desk`：Bootstrap 设计语言，蓝白企业门户，适合内容治理和多级导航。
- `C / Editorial Canvas`：Bulma 设计语言，技术杂志风格，适合突出博客与作者。
- `D / Signal Lounge`：Shoelace 设计语言，轻量协作客厅，社区氛围更友好。
- `E / Afterhours Edition`：编辑型杂志方向，非对称网格、超大标题和强品牌色，彻底减少后台感。

## 大厂组件库方向

- `Ant Design`：企业后台和内容治理风格。
- `Arco Design`：现代 SaaS 和社区内容流风格。
- `TDesign`：中文产品、工作台和社区门户风格。

每个方案都包含：

- 首页布局与响应式移动端结构
- 博客、工具箱、需求广场内容
- 内容分类筛选
- 搜索弹层
- 收藏或交互演示
- 返回选版入口

选定方向后，保留对应页面的布局、颜色和组件语言，再接入现有 `app.js` 的真实内容交互。
