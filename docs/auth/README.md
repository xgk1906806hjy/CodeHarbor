# 认证功能

## 范围

提供用户名、邮箱和密码注册；支持用户名或邮箱登录、退出和当前用户查询。页面启动时恢复会话，登录后个人入口显示用户名和邮箱。内容浏览仍对游客开放；目前发布和互动页面尚未实施服务端权限保护。

## 本地启动

在项目目录运行 `node server.js`，随后访问 `http://localhost:4173`。可使用 `CODEHARBOR_PORT` 指定端口，使用 `CODEHARBOR_DATA_DIR` 指定本地用户数据目录。当前实现依赖 Node.js 原生模块，不需要安装包。

## 接口

所有接口前缀为 `/api/v1/auth`，请求和响应均为 JSON。除退出接口外，写接口要求 `Content-Type: application/json`。

| 方法 | 路径 | 请求 | 成功响应 |
| --- | --- | --- | --- |
| POST | `/register` | `{ "username": "Kai", "email": "kai@example.com", "password": "至少6位" }` | 201，`{ "user": { "id", "username", "email", "createdAt" } }` |
| POST | `/login` | `{ "identifier": "用户名或邮箱", "password": "..." }` | 200，用户公开字段 |
| GET | `/me` | Cookie Session | 200，用户公开字段 |
| POST | `/logout` | Cookie Session | 200，`{ "ok": true }` 并清除 Cookie |

用户名为 2 至 24 位，只接受字母、数字、下划线、中文及连字符；邮箱最长 254 位；密码为 6 至 128 个字符。用户名不区分大小写唯一，邮箱在规范化为小写后唯一。重复账号返回 409；无效参数返回 400；凭证无效或会话失效返回 401；请求过多返回 429。密码在浏览器和本地开发服务之间传输，部署到非本机环境时必须启用 HTTPS。

## 安全与存储

- 密码使用 Node.js `crypto.scryptSync` 加盐哈希；用户公开响应不包含密码盐或摘要。
- 会话令牌为随机 256 位值，仅保存在 `HttpOnly; SameSite=Lax` Cookie 中，最长 7 天，登出或服务重启后失效。
- 注册按客户端地址每分钟最多 8 次；登录每分钟最多 12 次。限流和会话保存在服务进程内，多实例部署需改为共享存储。
- API 写操作校验请求来源；请求体上限为 16 KiB；静态文件使用白名单提供，`.runtime` 不对外公开。
- 本地账号存储于 `.runtime/auth-users.json`，以临时文件原子替换；该 JSON 文件不是多实例生产数据库。
- 账号唯一冲突返回明确提示，登录错误不区分账号不存在和密码错误。

## 当前边界

密码重置、邮箱验证、用户资料编辑、生产数据库、跨进程会话、账号锁定及登录操作审计尚未实现。当前发布、收藏、需求响应仍为前端本地演示，认证状态尚未用于这些操作的服务端授权。
