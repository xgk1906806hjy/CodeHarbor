# 工具箱功能说明

目标：沉淀在线工具、桌面工具、命令行、插件、开源项目和服务。

字段：名称、简介、详细说明、官方链接、源码链接、类型、场景、平台、语言、标签、提交者、审核状态和互动计数。

流程：提交 -> 校验字段和链接 -> 待审核 -> 发布 -> 浏览、访问、收藏和评价。

接口：GET /api/v1/tools、POST /api/v1/tools、GET /api/v1/tools/:id、PATCH /api/v1/tools/:id、DELETE /api/v1/tools/:id、POST /api/v1/tools/:id/visit。

规则：官方链接必填，HTTPS 优先；删除使用软删除；下架工具不出现在公开列表。验收：支持类型、平台、语言、标签筛选和收藏评价。
