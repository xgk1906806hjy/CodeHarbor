# CodeHarbor 功能文档索引

每个子目录对应一个业务功能，统一包含 README.md 和 CHANGELOG.md。README.md 记录功能目标、用户流程、数据、接口、权限、状态和验收标准；CHANGELOG.md 记录按时间追加的变更。

## 功能目录
- home：首页与信息流。
- auth：注册、登录和会话。
- blog：博客发布、阅读和管理。
- toolbox：工具提交、浏览和收藏。
- requirements：需求发布、响应和状态管理。
- interactions：点赞、收藏、评论、关注和通知。
- search：全局搜索、筛选和排序。
- moderation：审核、举报和内容治理。
- profile：个人资料和个人主页。
- admin：管理员后台。

## AI 修改规则
修改某个功能前先读取该目录两个文件；完成后更新 CHANGELOG.md。跨功能修改需要同步更新所有受影响目录。
