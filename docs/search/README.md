# 搜索功能说明

目标：让用户在博客、工具和需求之间通过一个搜索入口快速找到内容。

范围：搜索标题、摘要、正文、工具说明、需求描述、标签和技术栈；支持内容类型、分类、标签、时间、状态筛选，以及综合、最新、热度和收藏排序。

接口：GET /api/v1/search?keyword=&type=&page=&pageSize=&sort=；GET /api/v1/categories；GET /api/v1/tags。

规则：关键词为空时返回推荐或热门内容；分页参数限制最大值；排序字段使用白名单；公开搜索不返回草稿、下架和软删除数据。验收：类型可区分；无结果显示建议和发布入口；条件和分页可通过 URL 恢复。
